# QuickPost for Tumblr — informational website

Public, static website only. This repository does not contain the Chrome extension, OAuth backend, application credentials, signing keys or tokens.

GitHub Pages serves the root of `main`. The site uses plain HTML and CSS, no build pipeline, analytics scripts or external fonts.

- `index.html`: product information and development status.
- `privacy.html`: pre-release privacy policy; unresolved verification items are explicitly marked.
- `oauth1-callback.html`: static placeholder for the legacy registration field. The application uses OAuth 2.0.
- `styles.css`: responsive dark theme.

Contact: use this repository’s Issues tab. Do not include private account information, passwords, tokens or unpublished content in a public issue.

QuickPost is an independent project and is not affiliated with or endorsed by Tumblr.
